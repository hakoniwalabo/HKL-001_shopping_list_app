# 残課題一覧：v1.3.0+13 公開時点

**作成日**: 2026-10-22
**背景**: v1.3.0+13（リスト並び替え・予測候補へのよく買うもの追加）を 2026-10-21 に公開した時点で持ち越した課題をまとめます。いずれも未着手で、優先度順です。完了した項目は、このファイルに完了日を追記してください。

## 1. 公開後の安定性確認（数日後）
Play Console のクラッシュ率・ANR率を確認し、v8→v9 のDB移行に起因する異常がないかを見ます。公開直後は「-」表示で、判定できていません。

## 2. ダイアログ・DBのテスト基盤の整備
`sqflite_common_ffi` の導入と、`DatabaseHelper` のDB差し替え口を用意します。DB系（v9移行・`updateListOrder`・採番）には自動テストがなく、今回はレビューと実機確認のみで検証しました。

## 3. セキュリティレビューの参考指摘
詳細は `general/2026-10-21_v1.3.0-release-security-review.md` を参照してください。
- 参考1（確信度3・既存挙動）：インポートで取り込む「よく買うもの」の価格が未正規化で、候補選択時に入力欄へ負数が入り得ます。保存時の価格チェックで弾かれるため、不正値は保存されません。
- 参考2〜4（確信度2・優先度低）：`_loadFavorites` に例外処理がない点、並び替えを連続実行した場合の書き込み順序、マイグレーションの `catch (_)` が列重複以外の失敗も吸収する点です。

## 4. 並び替え機能の軽微な繰り越し事項
- `insertList` の MAX 取得と INSERT がトランザクションなしで実行されています（許容）。
- `onReorderItem` を tear-off にできます（コード整理）。
- 並び替えモード中は、選択中のリストが視覚的に分かりません（許容）。
- 並び替えモードの終了時に、商品一覧が一瞬再読込みされます（許容範囲と確認済み）。

## 5. Play Console の推奨対応（任意）
エッジ ツー エッジ表示、ビットマップのダウンサンプリング、R8 の最適化の3件が提案されています。リリースの妨げにはなりません。

## 6. 環境の後片付け
空フォルダ `.claude\worktrees\list-tab-reorder` が、別プロセスに掴まれて削除できていません。PC再起動後に削除します（git側は `git worktree prune` 済み）。
