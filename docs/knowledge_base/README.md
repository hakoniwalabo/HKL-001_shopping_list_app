# 開発ナレッジベース索引

HKL-001買い物リストアプリの開発過程で得られた調査レポート・セキュリティレビュー・手動チェック記録を機能・画面単位で整理したもの。新しい調査記録は該当カテゴリのフォルダに直接追加していく。索引は日付の降順（新しい順）で並べる。

## カテゴリ一覧

- `backup/` — バックアップ機能
- `budget/` — 予算表示機能
- `category/` — カテゴリ機能
- `favorites/` — お気に入り機能
- `history-removal/` — 履歴削除機能
- `list-share/` — リスト共有機能
- `purchase/` — 課金・広告削除（IAP）
- `general/` — 複数機能にまたがる横断的な内容。機能に紐づかない横断的な内容（フルスペックレビュー等）を置く。特定機能に紐づく内容は該当機能カテゴリに置くこと。
- `reusable_patterns/` — 他プロジェクトへ転用可能な実装パターン集（※他カテゴリは機能・画面軸だが、これのみ「再利用可能な実装パターン」という別軸のカテゴリ）
