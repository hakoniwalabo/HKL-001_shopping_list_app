# リリースノート v1.2.3+12

## 日本語（ja-JP）

・商品の追加・編集画面で、個数を空欄や0のまま保存しようとすると「1以上の整数を入力してください」というエラーを表示するようにしました。
・データの安定性を改善しました。

---

## English（en-US）

• On the add/edit item screen, saving with the quantity field left blank or set to 0 now shows the error "Please enter an integer of 1 or more".
• Improved data stability.
