# よく買うものダイアログ × ボタン変更 確認チェックリスト

対象コミット: favorites_dialog.dart — × ボタン化
確認日: 2026-06-29

## 基本動作

- [x] よく買うものダイアログを開いたとき、タイトル行右端に × アイコンが表示される
- [x] × ボタンをタップするとダイアログが閉じる
- [x] × ボタンをタップして閉じた後、メイン画面に正常に戻る
- [x] actions 行に「閉じる」テキストボタンが表示されていない
- [x] actions 行に「直接登録」「リストに追加」ボタンのみ表示される

## リストに追加フロー

- [x] 商品にチェックを入れて「リストに追加」が押せる
- [x] 「リストに追加」後にダイアログが閉じる
- [x] 追加した商品がメインリストに反映される

## 直接登録フロー

- [x] 「直接登録」ボタンをタップすると登録ダイアログが開く
- [x] 登録後によく買うものリストに商品が追加される

## 検索中の × ボタン

- [x] 検索欄に文字を入力した状態でタイトルの × をタップするとダイアログが閉じる
- [x] 検索欄のクリアボタン（× ）と競合しない

## キーボード表示中

- [x] 検索欄をタップしてキーボードが表示された状態で × ボタンが見える・押せる
- [x] キーボード表示中に × をタップするとダイアログが閉じる（オーバーフロー不発生）

## 回帰確認

- [x] 商品を左スワイプで削除できる
- [x] 削除後「元に戻す」が表示され、タップで復元できる
- [x] ドラッグハンドルで並び順を変更できる
- [x] 商品タップで編集ダイアログが開く
- [x] 全選択 / 全解除が正常に動作する
