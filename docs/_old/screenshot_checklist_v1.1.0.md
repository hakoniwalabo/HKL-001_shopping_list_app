# スクリーンショット構成チェックリスト v1.1.0

## 技術要件（Play Store）
- [ ] フォーマット：JPEG または 24bit PNG（アルファなし）
- [ ] サイズ：320px〜3840px、縦横比 1:2 以内
- [ ] 枚数：2〜8枚（推奨8枚）
- [ ] 向き：縦向き（ポートレート）

---

## 撮影画面リスト（推奨順）

### 1. メイン画面 — カテゴリ別セクション表示
- [ ] 複数カテゴリのセクションが見える状態（食品・日用品など）
- [ ] 未購入商品が各セクションに2〜3件ずつ並んでいる
- [ ] 購入済みセクションにも1〜2件ある
- [ ] 税込合計が表示されている

### 2. メイン画面 — 複数タブ
- [ ] タブが3〜4件ある状態（例：今週の買い物・業務用・常備品）
- [ ] 現在のリストに商品が並んでいる

### 3. よく買うもの — 一覧
- [ ] 定番商品が5〜8件登録されている
- [ ] 検索窓が見える
- [ ] カテゴリ名がついた商品が含まれている
- [ ] 複数件チェックされている状態

### 4. 商品追加ダイアログ
- [ ] 商品名・価格・個数・カテゴリ入力欄が見える
- [ ] カテゴリドロップダウンが展開されている（またはカテゴリが選択済み）

### 5. カテゴリ管理ダイアログ
- [ ] 複数カテゴリが一覧表示されている（3〜5件）

### 6. バックアップ・共有メニュー
- [ ] ⋮ メニューが開いた状態（バックアップ・読み込む・リストを共有等が見える）

### 7. よく買うもの — 検索絞り込み
- [ ] 検索窓に文字を入力して絞り込まれた状態

### 8. ヘルプ画面（任意）
- [ ] 機能一覧が見える状態
