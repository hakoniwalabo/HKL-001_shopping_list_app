# リリースノート v1.2.0+9

## 日本語（ja-JP）

・「よく買うもの」画面（AppBar右上のハートボタンから開く画面）を、ダイアログ表示から画面全体を使った表示に変更しました。
・カテゴリを登録している場合、「よく買うもの」の商品もメインのリスト画面と同様にカテゴリごとにグループ分けして表示されるようになりました。
・「よく買うもの」でも、各カテゴリ内で商品をドラッグして並べ替えられるようになりました（カテゴリをまたいだ並べ替えはできません）。
・検索・全選択・スワイプ削除＋元に戻す・商品タップでの編集など、既存の操作方法はそのままご利用いただけます。

---

## English（en-US）

• Changed the Favorites screen (opened from the heart button in the top-right of the AppBar) from a dialog to a full-screen view.
• When categories are set, Favorites items are now grouped by category, just like the main list screen.
• You can now drag to reorder items within each category in Favorites (reordering across categories is not supported).
• Existing actions such as search, select all, swipe to delete with undo, and tap to edit still work the same way.
