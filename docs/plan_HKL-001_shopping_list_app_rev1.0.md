## 1. アプリコンセプト

**「アカウント不要・オフライン完結の、速くて正直な買い物リスト」**

登録不要・ネット不要・広告あり無料で、起動直後から使える買い物リストアプリ。  
「いくら使うか」を意識しながら買い物できる価格・合計計算を中核に据え、  
シンプルな操作性と、一人暮らしから小家族まで使えるリスト管理機能を提供する。

### コンセプトを支える3つの軸

| 軸 | 内容 |
|----|------|
| **速さ** | 起動即使用・アカウント不要・オフライン完結。思い立ったその場でメモできる |
| **正直さ** | 税込単価×数量の合計をリアルタイム表示。「いくら使うか」を買い物前から把握できる |
| **続けやすさ** | よく買うもの登録・リスト複製・バックアップで、毎週の繰り返し作業を省力化する |

## 2. ターゲットユーザー

### プライマリターゲット

**節約意識のある個人・小家族（20〜50代 Android ユーザー）**

- 食費をなんとなくでなく「見える化」して管理したい人
- アカウント登録が面倒で、気軽に使い始めたい人
- Wi-Fi・電波の不安定な場所（スーパー地下・市場など）でも使いたい人

### セカンダリターゲット

- 一人暮らし・独身（即席メモ用途）
- 業務用と家庭用を使い分けたい小規模事業者（飲食店オーナー等）
- 夜勤などで不規則な生活リズムの人（看護師・介護職等）

### ターゲット外（現コンセプトでは対応しない）

- リアルタイム家族共有を主目的とするユーザー（OurGroceries・Bring! が適切）
- レシピ連携・在庫管理・家計簿統合を求めるユーザー
- iOS ユーザー（現状 Android 専用。将来対応予定）

## 3. 解決する課題

### ユーザーが抱える課題

| 課題 | 本アプリでの解決方法 |
|------|-------------------|
| 「買い物に行って何か忘れた」 | 商品履歴補完（Autocomplete）・よく買うもの登録で抜け漏れ防止 |
| 「レジで合計がいくらになるか分からない」 | 税込単価×数量の未購入合計をリアルタイム表示 |
| 「毎週同じリストを作り直すのが面倒」 | リスト複製・よく買うもの一括追加で省力化 |
| 「機種変更のたびにデータが消える」 | JSON バックアップ（共有・端末保存）で引継ぎ対応 |
| 「家族に買い物リストを渡したい」 | リスト共有（スナップショット送付）で一方向の受け渡しは可能 |
| 「アカウント作成が面倒でアプリを使い始められない」 | 登録ゼロ・起動即使用 |

### 解決しない課題（意図的なスコープ外）

- 複数人がひとつのリストをリアルタイムで同時編集する（クラウド同期は現コンセプト外）
- 月次食費グラフ・予算超過警告（家計簿アプリの領域）
- 商品のカテゴリ自動分類・店舗の売り場動線への対応

## 4. 競合との差別化

### 差別化ポイント

| 特徴 | 本アプリ | Google Keep | OurGroceries | AnyList |
|------|---------|-------------|--------------|---------|
| アカウント不要 | **✅** | ❌（Google必須） | ❌ | ❌ |
| オフライン完結 | **✅** | ❌ | ❌ | ❌ |
| 税込合計計算 | **✅** | ❌ | ❌ | △（有料） |
| リスト複製 | **✅** | ❌ | ❌ | ❌ |
| よく買うもの管理 | **✅** | ❌ | ✅ | ✅ |
| バックアップ・引継ぎ | **✅（JSON）** | ✅（Drive） | ✅（クラウド） | ✅ |
| リアルタイム家族共有 | ❌ | ✅ | ✅ | ✅（有料） |
| iOS 対応 | ❌ | ✅ | ✅ | ✅ |

**「アカウント不要×オフライン×合計計算」の組み合わせが競合にない独自ポジション。**

### ポジショニング

```
               ↑ 価格・合計計算あり
               │
  本アプリ     │    AnyList
（ローカル完結）│   （クラウド同期）
               │
───────────────┼───────────────→ クラウド共有
               │
  Google Keep  │  OurGroceries
（シンプルメモ）│  （家族共有特化）
               │
               ↓ 価格・合計計算なし
```

## 5. 機能スコープ（Rev 8.4 時点）

### コア機能（外せない）

- 商品追加・編集・スワイプ削除・Undo 復元
- 購入済みチェック・一括削除
- 税込単価×数量の合計表示（未購入・購入済み並列）
- 複数リスト管理（最大10・タブ式）

### 差別化機能（このアプリらしさ）

- よく買うもの登録・一括追加
- リスト複製・別リストへの商品移動
- 商品履歴補完（Autocomplete・使用回数順）
- バックアップ（共有・端末保存）・リスト共有（スナップショット）

### 収益化機能

- AdMob バナー広告（無料ユーザー向け）
- 広告なし買い切り IAP（`remove_ads`）

### 意図的に持たない機能（現バージョン）

- クラウド同期・リアルタイム共有
- アカウント・ログイン機能
- カテゴリ分類・売り場動線対応
- 予算設定・月次集計・グラフ
- 音声入力・ウィジェット

---

## 6. 収益モデル

| 収益源 | 対象ユーザー | 内容 |
|--------|------------|------|
| AdMob バナー広告 | 無料ユーザー全員 | 画面下部固定。操作の邪魔にならないバナーのみ |
| 広告なし買い切り（IAP） | 広告を消したいユーザー | 一度購入で永久に広告非表示。価格はストアで設定 |

サブスクリプションは採用しない。「買い切りで終わり」のシンプルな収益構造を維持する。

## 7. 今後の拡張候補

現コンセプトを壊さない範囲での拡張優先度。

| 優先度 | 機能 | 理由 |
|--------|------|------|
| 高 | カテゴリ機能 | 仮想テストで複数テスターが要望。スーパー動線への対応はコア用途に直結 |
| 高 | iOS 対応 | 将来ロードマップ確定。Flutter のマルチプラットフォーム利点を活かせる |
| 中 | ウィジェット対応 | 起動不要のクイックアクセス。「速さ」の軸を強化 |
| 中 | 予算上限設定・超過表示 | 「正直さ」の軸の延長。合計計算の自然な次のステップ |
| 低 | Firebase 同期 | リアルタイム共有の実現手段。ただしコンセプト変更を伴うため慎重に判断 |
| 低 | WearOS 対応 | ウォッチで買い物リストを確認。ニッチだが差別化になる |
