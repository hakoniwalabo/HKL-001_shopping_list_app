# リリースノート v1.2.2+11

## 日本語（ja-JP）

・買い物リストごとに「予算」を設定できるようになりました。設定した予算と現在の合計金額を並べて確認できます。
・未購入合計・購入済合計の金額が0円のとき、表示を「－」に統一しました。
・「未購入」「購入済」の表記を「未チェック」「チェック済」に統一しました。
・ヘルプ画面に予算設定の使い方の説明を追加しました。

---

## English（en-US）

• You can now set a "budget" for each shopping list and compare it with the current total amount.
• Unified the display to "－" when the unchecked/checked total amount is 0 yen.
• Unified the terminology from "unpurchased/purchased" to "unchecked/checked".
• Added an explanation of how to set a budget to the Help screen.
