# リリースノート v1.1.0+7

## 日本語（ja-JP）

・バックアップを読み込んだ後、カテゴリの表示が更新されない不具合を修正しました。
・バックアップを読み込んだ後、読み込んだリストに自動的に切り替わらない不具合を修正しました。
・バックアップを読み込んでからリスト名を変更し、アプリを再起動すると商品が空表示になる不具合を修正しました。
・バックアップを読み込んだとき、新しいリストが常にタブの右端に追加されるよう改善しました。
・アプリ起動時、常に一番左のタブ（リスト）が表示されるよう改善しました。

---

## English（en-US）

• Fixed categories not updating after loading a backup.
• Fixed app not switching to the loaded list after import.
• Fixed empty items after list rename and app restart.
• New lists from backup are now added to the rightmost tab.
• App now always opens to the leftmost tab on launch.
