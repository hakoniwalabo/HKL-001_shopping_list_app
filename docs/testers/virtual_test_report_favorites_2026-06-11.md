# よく買うもの機能 仮想テストレポート

**テスト日：2026-06-11**
**対象バージョン：** HKL-001 買い物リストアプリ（設計書 Rev 8.2 ベース）
**テスト実施：** 仮想テスト（標準テスターペルソナ 10名）

---

## テストパターン概要

| パターン | 内容 | 実装コスト |
|---------|------|----------|
| **パターン A**（フル実装） | ♡ ボタン・FavoritesDialog・HistorySelectDialog・DB v6 favorites テーブル | 高 |
| **パターン B**（デフォルトリスト） | インストール時に「よく買うもの」という空リストをデフォルト追加 | 低（INSERT 1行） |

### 結論と推奨

**パターン A（フル実装）が全体的に優位。** 選択追加・永続 favorites・リスト上限非依存の3点が大きな強み。8/10 テスターで A が優位または同等の結果となった。

**パターン B が優位なのは06（渡辺誠一）と09（加藤里奈）の2名のみ。** 命名の明快さと price=0 問題の回避は評価できるが、複製増殖とチェック汚染が致命的。

**推奨アクション（パターン A 採用時）：**

| 優先度 | 対応 |
|--------|------|
| 🔴 高 | よく買うもの一覧に**編集機能**を追加（タップで名前・価格・個数を編集） |
| 🔴 高 | 高齢者向けに ♡ ボタンに**ラベルテキスト追加**または長押し削除に**確認ダイアログ**追加 |
| 🟡 中 | **全選択 / 全解除ボタン**を FavoritesDialog に追加 |
| 🟡 中 | 履歴登録後の price=0 に**「価格未設定」バッジ**または登録直後の編集促進 UI |
